# Traditions Mockup

A static, mobile-first recreation of the supplied screenshots for visual/demo use.

## Files

- `index.html` — page markup
- `style.css` — responsive styling
- `script.js` — tiny interaction helper
- `dummy-qr.png` — harmless demo QR pointing to example.com

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub + Netlify

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In Netlify, choose **Add new site → Import an existing project**.
4. Connect GitHub and select the repository.
5. This is a plain static site, so no build command is needed.
6. Publish directory: leave blank or use `/`.

Once deployed, open the Netlify URL on your iPhone. The browser itself supplies the Safari/Chrome address and navigation bars, while this page supplies the scrollable order content.

The QR in this project is intentionally a demo QR and is not a meal-plan or payment credential.
